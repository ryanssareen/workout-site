### Features

1. Next.js 16 with App Router, React 19, TypeScript 5.9
2. Firebase Authentication (email/password + Google Sign-In)
3. Firebase Firestore (real-time data storage)
4. Zustand state management
5. Groq SDK (LLaMA 3.3 70B + 8B instant fallback) and OpenAI SDK for workout suggestions and reports
6. Model Context Protocol (MCP) server v3.0.0
7. Email notifications via Nodemailer and Brevo
8. Strava API integration (OAuth + webhooks)
9. PostHog analytics
10. Custom workouts with AI recommendations
11. Calendar and dashboard views
12. Onboarding and file upload functionality
13. Duplicate workout detection
14. Strava sync functionality
15. Manual merge dialog
